---
title: 传送
description: 将玩家或实体传送到绝对、相对或命名目的地。
version: "1.0.0"
---

将动作的目标实体传送到绝对坐标、相对于其当前位置的坐标或命名目的地。

## 坐标目的地

三个坐标轴都必须提供。数值保持为绝对坐标，并与现有配置兼容。

```yaml
teleport:
  x: 100
  y: 64
  z: -50
```

在带引号的坐标前加 `~`，即可使其相对于被传送的实体。`"~"` 保持当前坐标，`"~10"` 增加 10，`"~-2.5"` 减少 2.5。

```yaml
teleport:
  x: "~10"
  y: "~"
  z: "~-2.5"
```

绝对坐标轴和相对坐标轴可以混合使用：

```yaml
teleport:
  x: 100
  y: "~5"
  z: "~-2"
```

相对坐标始终以目标实体的当前位置为基准，而不是触发动作的玩家。空白、格式错误、NaN 和无限值都会被拒绝。

## 命名目的地

使用 `destination` 代替 `x`、`y` 和 `z`。坐标不能与命名目的地同时配置。

### 世界出生点

```yaml
teleport:
  destination: world_spawn
```

`world_spawn` 使用目标实体当前所在的世界。设置 `world` 可使用另一个已加载世界的出生点：

```yaml
teleport:
  destination: world_spawn
  world: "world_nether"
```

### 玩家重生点

```yaml
teleport:
  destination: respawn
```

`respawn` 使用触发动作的玩家的重生位置，包括床和重生锚。如果玩家没有有效的重生位置，则回退到所配置世界的出生点；省略 `world` 时，回退到玩家当前世界的出生点。

动作仍会传送目标实体。触发动作的玩家仅用于解析重生位置。

## 可选参数

### `yaw` 和 `pitch`

绝对旋转值。使用坐标时，省略的值会保留目标实体当前的旋转；使用命名目的地时，省略的值会保留该目的地的旋转。

```yaml
teleport:
  destination: respawn
  yaw: 90.0
  pitch: 0.0
```

### `world`

使用坐标或 `world_spawn` 时，默认使用目标实体当前所在的世界。使用 `respawn` 时，仅在玩家没有重生位置时作为回退世界。所配置的世界必须存在并已加载。
